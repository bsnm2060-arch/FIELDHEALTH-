# FIELDHEALTH — نسخة Android جاهزة للبناء

**الاسم:** فيلد هيلث | FIELDHEALTH  
**الهوية:** خ م — اختصار خضر المطر  
**العنوان المختصر:** المراقبة الصحية والبيئية الميدانية دون اتصال بالإنترنت

## ما تم إصلاحه
- واجهة عربية كاملة من اليمين إلى اليسار.
- تشغيل JavaScript وLocal Storage داخل WebView.
- إصلاح زر الرجوع في Android: يعود داخل صفحات WebView قبل إغلاق التطبيق.
- إضافة أيقونة التطبيق.
- منع الوصول غير الضروري للاتصالات غير المشفرة.
- دعم RTL ونسخ احتياطي معطل لتقليل تسرب بيانات النموذج الأولي.

## إنشاء APK بدون تثبيت Android Studio
المشروع يحتوي على Workflow في `.github/workflows/build-apk.yml`.

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتويات مجلد `FIELDHEALTH_Android` إلى الفرع `main`.
3. افتح تبويب **Actions**.
4. اختر **بناء تطبيق FIELDHEALTH APK**.
5. انتظر اكتمال البناء.
6. افتح نتيجة التشغيل ثم نزّل artifact باسم **FIELDHEALTH-debug-APK**.

## بناء محليًا
باستخدام Android Studio افتح مجلد `FIELDHEALTH_Android` ثم نفّذ Build APK. وفق توثيق Android الرسمي، يمكن بناء وتشغيل التطبيق من Android Studio، كما أن Run الافتراضي يبني APK للتجربة. 

الناتج المتوقع:
`app/build/outputs/apk/debug/app-debug.apk`

- فتح التطبيق.
